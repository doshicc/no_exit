# NO EXIT — Зомби-выживалка с видом сверху

**NO EXIT** — это динамичная 2D игра в жанре «выживание с видом сверху» (twin-stick shooter) с элементами рогалика. Игроку предстоит пробиваться через процедурно генерируемые комнаты, заполненные зомби, собирать усиления и стараться продержаться как можно дольше.

Проект написан на **Java** с использованием игрового фреймворка **LibGDX** и физического движка **Box2D**.

## 🎮 Особенности

- 🧟 **Динамические враги** — зомби преследуют игрока, атакуют и могут оставлять после себя полезные предметы
- 🗡️ **Система ближнего боя** — атака по области с угловым ограничением (конус атаки)
- 🏠 **Процедурная генерация уровней** — комнаты, коридоры, стены и декорации создаются случайным образом
- 💊 **Система усилений (Power-Ups)**:
  - ❤️ Лечение
  - 🛡️ Дополнительное сердце (щит)
  - ⚡ One-Shot — мгновенное уничтожение всех зомби в комнате
- 📱 **Сенсорное управление** (виртуальные джойстики) — игра оптимизирована для мобильных устройств
- 🔊 **Настройки звука** — раздельное включение/выключение фоновой музыки в меню и игре, а также звуковых эффектов
- 🎨 **Покадровая анимация** — Idle, Walk, Attack, Death для игрока и зомби
- 💾 **Сохранение настроек** — через Preferences API

## 🧠 Игровая механика

### Комнаты
- Игра начинается в первой комнате
- После уничтожения всех зомби открывается проход в следующую комнату
- Каждая следующая комната находится правее предыдущей, соединена коридором
- Стены, полки, ящики создают препятствия

### Здоровье
- У игрока **3 сердца** (можно расширить до 4 через щит)
- При получении урона — кратковременная неуязвимость
- При полной потере здоровья — экран поражения с выбором: «Играть снова» или «Выйти в меню»

### Бой
- Атака — конус шириной 70 градусов, радиус — 2.8 метра
- При атаке все зомби в конусе получают урон
- Зомби оглушаются и отбрасываются
- Зомби умирают с 3 попаданий

## 🗂️ Структура проекта (основные классы)
com.mygdx.game/
├── Assets.java # Централизованная загрузка всех ресурсов
├── MyGdxGame.java # Главный класс игры (наследует Game)
├── Settings.java # Работа с настройками (Preferences)
├── B2DVars.java # Константы для Box2D (масштаб, биты фильтрации)
├── enums/
│ └── EntityState.java # Состояния сущностей (IDLE, WALK, ATTACK, DEATH)
├── objects/
│ ├── Player.java # Логика игрока (физика, анимация, атака, здоровье)
│ ├── EnemyZombie.java # Логика зомби (AI, анимация, выпадение баффов)
│ └── PowerUp.java # Усиления (HEAL, SHIELD, ONE_SHOT)
├── screens/
│ ├── MenuScreen.java # Главное меню
│ ├── PlayScreen.java # Основной игровой экран
│ └── SettingsScreen.java # Экран настроек
├── renderers/
│ └── LevelRenderer.java # Отрисовка комнат (пол, стены, объекты)
├── managers/
│ ├── BodyFactory.java # Создание физических тел Box2D
│ ├── LevelManager.java # Генерация комнат и их физики
│ └── AttackListener.java # Обработчик столкновений (урон от зомби)
├── data/
│ └── RoomData.java # Данные одной комнаты (карта пола, список тел Box2D)
└── ui/
├── View.java # Базовый UI-элемент
└── TextView.java # Текстовый элемент на экране


## 🚀 Запуск проекта

### Требования
- JDK 8 или новее
- Gradle (или использовать встроенный gradle-wrapper)
- Android SDK (для сборки под Android) — опционально

### Инструкция (Desktop)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/doshicc/no-exit.git
   cd no-exit
2. Запустите основной класс MyGdxGame.java (метод main должен быть реализован в десктопном лаунчере — в предоставленных файлах его нет, но обычно он создаётся отдельно в модуле desktop).
