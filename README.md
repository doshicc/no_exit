# No Exit

No Exit — 2D survival action игра для Android, разработанная на Java с использованием LibGDX и Box2D.

Игрок оказывается заперт в серии комнат, заполненных зомби. Чтобы продвигаться дальше, необходимо зачищать комнаты от врагов, собирать бонусы и использовать доступные улучшения для выживания.

## Особенности

### Игровой процесс

* Генерация последовательности комнат.
* Переход между комнатами через коридоры.
* Волны противников различных типов.
* Система ближнего боя.
* Управление двумя виртуальными джойстиками:

  * левый — движение персонажа;
  * правый — направление атаки.

### Типы врагов

* Обычный зомби.
* Быстрый зомби (Runner).
* Толстый зомби (Fat Zombie).

Каждый тип обладает собственными характеристиками скорости, здоровья и поведения.

### Бонусы

После уничтожения врагов могут выпадать случайные бонусы:

* Восстановление здоровья.
* Дополнительная жизнь.
* Мгновенное уничтожение всех врагов в комнате.

### Турели

Игрок может устанавливать турели (кнопка 1), которые автоматически атакуют ближайших врагов.

### Магазин

* Накопление монет за прохождение комнат.
* Покупка дополнительных турелей.
* Сохранение прогресса между игровыми сессиями.

### Обучение

Для новых игроков реализована система пошагового обучения:

1. Передвижение персонажа.
2. Уничтожение первого противника.
3. Подбор бонусов.

### Катсцена

При первом запуске игры отображается вступительная катсцена в формате слайд-шоу с сюжетным текстом.

## Используемые технологии

* Java
* LibGDX
* Box2D
* Scene2D UI
* Android SDK

## Архитектура проекта

### Основные экраны

* MenuScreen — главное меню.
* IntroScreen — вступительная катсцена.
* PlayScreen — игровой процесс.
* SettingsScreen — настройки.

### Менеджеры

* LevelManager — создание комнат.
* ShopManager — управление магазином и валютой.
* TutorialManager — логика обучения.
* BodyFactory — создание физических объектов.
* AttackListener — обработка столкновений.

### Игровые объекты

* Player
* EnemyZombie
* ZombieRunner
* ZombieFat
* PowerUp
* Turret

## Сохранение данных

Сохраняются:

* настройки звука и музыки;
* прохождение вступительной катсцены;
* завершение обучения;
* количество монет;
* количество купленных турелей.

## Управление

### Мобильные устройства

* Левый джойстик — движение.
* Правый джойстик — направление атаки.
* Кнопка установки турели.

### ПК (для тестирования)

* WASD — движение.
* Правая область управления — атака.
* 1 — установка турели.

## Цель игры

Продержаться как можно дольше, проходя комнаты и уничтожая всё более опасные волны противников.
